Methodology & limitations

WebShield is a defensive first-pass checker for basic website configuration hygiene. It is not a penetration-testing platform.

What it checks

  • HTTPS usage and TLS certificate verification.
  • Presence of common security headers such as CSP, HSTS, Referrer-Policy, and X-Content-Type-Options.
  • HTTP response status and redirect behavior.
  • HTML title, meta description, favicon link, and viewport metadata.
  • A bounded sample of links, with a configurable limit.

Safety controls

  • Requires an explicit authorization confirmation before scanning.
  • Blocks hostnames that resolve to private, loopback, link-local, reserved, or otherwise non-public IP addresses.
  • Validates redirect destinations before making the next request and does not automatically follow redirects.
  • Uses TLS certificate verification, request timeouts, response-size limits, and rate limiting.
  • Uses parameterized SQL statements for scan history and reports.

Important limitations

DNS rebinding and network-level changes can be difficult to eliminate completely in an application-level URL fetcher. For production, run scanning in a dedicated isolated worker/container with strict egress firewall rules, DNS controls, and a hardened proxy. This application should not be exposed as an unrestricted public URL-fetching service.

Some sites block automated requests, require JavaScript, or treat HEAD requests differently. A link marked unreachable may not be truly broken. The tool does not test authentication flows, authorization, SQL injection, XSS, CSRF, API access control, source code, or browser-rendered layout overflow.

Score interpretation

The displayed score is a simple checklist score derived from detected findings. It is not an industry-standard rating, risk probability, certification, or guarantee of security. Manually validate findings and prioritize them using your application's context.

Responsible use

Only scan websites you own or have explicit permission to assess. Keep scans low-volume. Do not use the scanner to bypass access controls, probe private systems, or disrupt services.
